# Safety and security

This repository documents an unofficial, reverse-engineered interface to ventilation hardware. Treat all undocumented write operations as potentially unsafe.

For safety-related findings, avoid publishing instructions that could cause equipment damage. For repository security issues, open a GitHub issue containing only non-sensitive information and indicate that further details should be exchanged privately.

Never publish access tokens, passwords, private network details, device serial numbers, or other credentials in issues, pull requests, logs, or scan data.
